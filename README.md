# Netfree Guard

אפליקציית אנדרואיד אישית (לא לפרסום בחנות) שמשלבת:

1. **התקנת תעודות ה-CA של נטפרי** לחנות תעודות המערכת - דורשת אישור root
   פעם אחת בלבד, בעת לחיצה על הכפתור "התקן תעודות".
2. **מעקב אחרי הרשת** ובדיקה אם היא מסוננת (`FilterCheck.kt`) על ידי חיבור
   לכתובת שאתה מגדיר בעצמך במסך ההגדרות.
3. **חסימת אינטרנט ברשתות לא מסוננות** באמצעות `VpnService` תקני של
   אנדרואיד (בלי root, בלי לגעת בהגדרות מערכת) - `LocalBlockVpnService.kt`.

## חשוב לדעת לפני שאתה משתמש בזה

- **אין לי כתובת בדיקה רשמית ומאומתת של נטפרי.** את שדה "כתובת בדיקה"
  צריך למלא בעצמך, מול נטפרי/התמיכה שלהם, עם host:port שבאמת מזהה חיבור
  דרך תשתית הסינון שלהם. בלי זה האפליקציה תיטה לחסום הכל (ליתר בטחון).
- **איפוס יצרן מוחק הכל** - גם את התעודות שהותקנו, גם את האפליקציה. זו
  התנהגות מכוונת ותקינה (ראו את השיחה שקדמה לקוד הזה) - לא באג.
- כשה-VPN החוסם פעיל, **אנדרואיד מציג אייקון מפתח קבוע** בשורת הסטטוס.
  זו התנהגות מובנית של המערכת ולא ניתן (ולא ראוי) לעקוף אותה - היא קיימת
  כדי שתמיד תדע שיש VPN/חסימה פעילים במכשיר שלך.
- הבדיקה שכתבתי (`Socket().connect`) היא בדיקת **הגעה בסיסית** לכתובת
  ולפורט בלבד. אם ההיגיון האמיתי אצל נטפרי הפוך (למשל: הכתובת דווקא
  **נחסמת** ברשת מסוננת ולא נענית) - סמן את "invert logic" ב-
  `SettingsStore` (כרגע קבוע בקוד ל-false; אפשר להוסיף לו כפתור במסך אם
  תרצה).

## איך לבנות (APK)

1. התקן [Android Studio](https://developer.android.com/studio) (חינמי).
2. פתח את התיקייה הזו (`NetfreeGuard`) כפרויקט קיים: File → Open.
3. חכה ל-Gradle Sync (אוטומטי, דורש אינטרנט בפעם הראשונה).
4. חבר את הטלפון (או השתמש באמולטור) ולחץ Run (▶) - או Build → Build
   Bundle(s)/APK(s) → Build APK(s) כדי לקבל קובץ APK להתקנה ידנית.
5. התקן את ה-APK במכשיר (יידרש לאשר "התקנה ממקורות לא ידועים" כי זו לא
   חנות Play).

## שימוש

1. פתח את האפליקציה → "התקן תעודות נטפרי" → אשר את בקשת ה-root שתופיע
   מ-Magisk (או מנהל ה-root שלך).
2. מלא את שדה כתובת הבדיקה ולחץ "שמור".
3. הפעל את המתג "הפעל הגנה" → אשר את בקשת ה-VPN (בקשה חד-פעמית של
   אנדרואיד, לא קשורה ל-root).

מרגע זה, בכל שינוי רשת האפליקציה בודקת אם היא מסוננת ותחסום אינטרנט
אוטומטית אם לא.
